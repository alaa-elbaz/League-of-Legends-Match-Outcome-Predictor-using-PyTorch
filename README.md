# League-of-Legends-Match-Outcome-Predictor-using-PyTorch
An end-to-end Machine Learning pipeline built from scratch using PyTorch to predict League of Legends match outcomes (Win/Loss). Features a custom Logistic Regression network (nn.Module), handwritten training loops, L2 regularization (weight decay), hyperparameter tuning, and comprehensive evaluation (Confusion Matrix &amp; ROC-AUC)
